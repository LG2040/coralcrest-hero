# CoralCrest hero

Interactive 3D logo hero for coralcrestconsulting.com, served by GitHub Pages.

- `index.html` - the hero page (dark stage, 3D mark, headline, Explore button)
- `coralcrest-logo.glb` - the 3D mark (1.2 MB, quantized, no decoder needed)

Embed on the site with an iframe pointing at the Pages URL. Add `?next=<url>` to make the
Explore button send the visitor to that address (for example a Wix anchor on the same page).

- `services.html` - full rebuilt Services page (hero, four service lines, REEF Method, who it's for, contact)
